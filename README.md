# 高性价比人生指南

> 核心思想：人生是一场资源交易。
> 你拥有四种不可再生资源：**寿命、时间精力、金钱、选择权（自由）**。
> 性价比，不是一味省钱，而是衡量：**为一件事付出的资源，能不能换回长期、真实、落在你身上的收益**。
> 这份文档是一份参考清单，不必全部照做，按需挑选适合自己的条目。

## 第一章 不要早死（最高优先级，收益最大）
健康是所有一切的基础，很多极低成本行为，能大幅降低意外、重病死亡风险。
1. 乘车系安全带；骑电动车/摩托车，头盔务必扣紧卡扣，不扣约等于无效。
2. 家中安装烟雾报警器；冬季燃煤、燃气取暖，加装一氧化碳报警器。
3. 不抽烟，尽量远离二手烟；酒精属于一类致癌物，尽量少喝或不喝。
4. 保证基础睡眠，长期连续熬夜会显著提升多种疾病风险。
5. 过马路不看手机；雨天、夜间出行提高警惕。
6. 控制基础慢性病：高血压、高血脂、血糖，遵医嘱服药，不要自行停药。
7. 合理用油，减少反复高温煎炸油；少吃霉变食物。
8. 掌握基础急救：海姆立克急救法、心肺复苏，学会拨打120清晰描述地址。

## 第二章 不要慢慢死（慢性病预防，低成本长期收益）
1. 每周150分钟中等强度运动（快走、骑车、慢跑都行），不必去健身房。
2. 多吃蔬菜，少加工肉类，减少高糖饮料。
3. 每年基础体检，重点项目按需筛查，不盲目做全套昂贵体检套餐。
4. 保护牙齿：每天认真刷牙+牙线，口腔疾病会带来长期身体负担与高额治疗费。
5. 不要长期久坐，每坐40~60分钟起身活动几分钟。

## 第三章 不要浪费精力（情绪、社交、内耗）
精力比时间更稀缺。时间可以安排，情绪内耗会悄无声息耗尽你。
1. 远离持续消耗你的人际关系，不必强迫自己讨好所有人。
2. 减少无意义刷短视频：算法内容短期刺激，长期消耗专注力。
3. 拒绝精神内耗：很多人对你的评价，并不影响你的真实生活，不必反复回想。
4. 学会拒绝，不要为了面子答应超出能力的请求。
5. 减少拖延：大任务拆成5分钟就能启动的小事，降低启动阻力。
6. 社交原则：高质量少量关系，远优于大量浅层无效社交。

## 第四章 不要浪费时间
时间一旦消耗，无法赎回。
1. 不要长期在没有成长、没有回报的工作里耗着，及时评估机会成本。
2. 学习优先选**长期复用技能**：阅读、写作、基础法律常识、沟通、健康知识。短期网红技能容易过时。
3. 减少等待型浪费：排队、通勤碎片时间，可以用来听有用内容，不要无意义刷手机。
4. 做决定不要无限纠结，收集关键信息后，设置截止时间。
5. 不要反复回看已经发生、无法改变的事情。

## 第五章 不要浪费钱（消费、理财、防坑）
核心：赚钱靠机遇，少亏钱靠认知。
1. 消费底层原则：**不需要的东西，再大折扣也是亏损**。
2. 避开预付卡陷阱：健身房、美容店大额储值，商家跑路维权成本极高，尽量少充。
3. 定期检查软件自动续费，很多项目长期默默扣费。
4. 远离网贷、消费贷，非救命场景绝不使用。
5. 理财：普通人优先保本，不要幻想低投入暴富；不碰高杠杆投机。
6. 不迷信名牌溢价，分清「功能刚需」和「情绪溢价」。
7. 保险顺序：先医保，再意外险、百万医疗险；最后再考虑重疾险，优先保障家庭经济支柱。
8. 警惕刷单、高息理财、投资导师荐股，基本都是骗局。

## 第六章 法律与财产安全，别把自己搭进去
1. 不要随便出借身份证、银行卡、电话卡，涉嫌帮信罪。
2. 打工被欠薪、无故辞退，保留证据，知道劳动仲裁渠道。
3. 不随意签字，合同、借条逐行看清楚，不盲目担保。
4. 租房、买卖物品保留聊天、转账凭证。
5. 网络发言守住底线，不造谣、不网暴。

## 第七章 婚恋与家庭，评估长期成本
1. 婚恋优先看：人品、责任感、情绪稳定，而不是短期浪漫。
2. 生育是极高成本选择，慎重评估经济、精力、家庭支持，不要随大流。
3. 和家人沟通：不必强行改变对方，守住自己边界。

## 第八章 职场、失业兜底
1. 不要裸辞毫无准备，先存3~6个月生活费应急金。
2. 了解社保：失业金、工伤报销等权益。
3. 持续积累可迁移能力，不要只做单一重复流水线工作。
4. 不要和公司签署明显不公平的协议。

## 第九章 看病就医，省钱少走弯路
1. 小病优先公立社区医院，大病再去三甲；不要迷信私立高价理疗保健。
2. 遵医嘱，不要乱吃保健品替代药品。
3. 看病带齐既往检查报告，避免重复做高价检查。
4. 拒绝医院门口的“医托”。

## 第十章 紧急情况与重大打击
1. 遭遇重大变故，优先保证基础生存，不要急于做重大决定（买房、大额投资、辞职）。
2. 心理崩溃时，主动求助，心理疾病和感冒一样，需要正规治疗。
3. 保管重要证件复印件/扫描件，单独云端备份。

## 反面清单：性价比极低的事
- 为面子透支消费
- 长期和烂人纠缠，反复争吵
- 熬夜换取短暂娱乐
- 幻想一夜暴富，投入积蓄博高收益
- 盲目跟风创业，掏空家底
- 为讨好别人不断牺牲自己健康、金钱

## 后记
高性价比人生，不是苦行、不是抠门，而是**把有限资源，投给那些长期稳定回报的事**。
不用一次性全部执行。每次只挑选1~2条落地，长期积累，人生状态会明显改善。

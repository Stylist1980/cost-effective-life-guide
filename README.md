# 高性价比人生指南 HowToLiveBetter

> 一句话宗旨：**用最少的钱、时间和精力，换回寿命、金钱与自由。**
> 这不是必须完成的任务清单，是一份人生备选参考手册，按需挑选适合自己的条目即可。
> 每条包含【成本】【说人话】【收益】【证据等级】【来源】。
> 证据分级：A 强证据（荟萃分析/大规模随机对照试验）；B 观察队列研究；C 法规、案例、经验推断。
> ⚠️医疗相关内容仅供参考，诊疗请遵从执业医师指导；理财内容不构成投资建议；法律条文以最新官方版本为准。

# 1. 不要早死
> 主题：规避车祸、火灾、中毒等意外死亡；高证据疫苗、疾病预警信号。

1. **乘车全程系安全带**
- 成本：几乎无成本，养成习惯
- 说人话：安全带大幅降低车祸死亡与重伤概率
- 收益：车祸致死风险降低约45%，重伤风险降低50%
- 证据等级：A
- 来源：Cochrane系统综述

2. **骑电动自行车/摩托车佩戴头盔，并且扣紧卡扣**
- 成本：100–300元，一次性购买
- 说人话：头盔不扣卡扣，防护效果基本失效
- 收益：死亡风险下降42%，头部重伤下降69%
- 证据等级：A
- 来源：Cochrane系统综述

3. **家庭安装烟雾报警器**
- 成本：几十元，电池一年一换
- 说人话：夜间火灾多数死于烟雾窒息，报警器提前预警
- 收益：住宅火灾死亡风险降低约一半
- 证据等级：B
- 来源：美国消防协会统计

4. **燃煤、燃气取暖，加装一氧化碳报警器**
- 成本：几十元
- 说人话：无色无味一氧化碳中毒常在睡眠中致人死亡
- 收益：避免无声中毒致死
- 证据等级：B
- 来源：疾控中心中毒统计

5. **不吸烟，远离二手烟**
- 成本：放弃吸烟开销，克制烟瘾
- 说人话：烟草为一类致癌物，缩短寿命，诱发心脑血管、肺部疾病
- 收益：戒烟后5年内中风风险显著回落，长期预期寿命大幅提升
- 证据等级：A
- 来源：多项大型队列荟萃分析

6. **尽量不饮酒，酒精属于一类致癌物**
- 成本：放弃酒水开销
- 说人话：不存在安全的“有益健康”饮酒量，喝越多风险越高
- 收益：降低肝癌、消化道癌、卒中风险
- 证据等级：A
- 来源：柳叶刀全球疾病负担研究

7. **保证基础睡眠，拒绝长期连续熬夜**
- 成本：牺牲夜间娱乐时间
- 说人话：长期睡眠不足升高心血管疾病、猝死、抑郁风险
- 收益：稳定作息降低全因死亡风险
- 证据等级：B
- 来源：长期队列研究

8. **过马路不看手机；雨天、夜间出行加倍警惕**
- 成本：放下手机的习惯
- 说人话：分心步行是行人交通事故重要诱因
- 收益：降低行人撞击事故概率
- 证据等级：B
- 来源：交通伤害流行病学

9. **高血压、高血脂、糖尿病，遵医嘱服药，不要自行停药**
- 成本：药费，定期复查时间
- 说人话：慢性病无症状阶段也持续损伤血管，擅自停药极易诱发心梗、脑梗
- 收益：显著降低卒中、心梗、肾病失明风险
- 证据等级：A
- 来源：大型降压降糖临床试验

10. **食用油不要反复高温煎炸；不吃霉变食物**
- 成本：更换新油，丢弃发霉食材
- 说人话：反复高温油、霉变花生玉米产生强致癌物黄曲霉素
- 收益：降低消化道肿瘤风险
- 证据等级：B
- 来源：毒理学与流行病学

11. **学会海姆立克急救法、心肺复苏，掌握120规范报地址**
- 成本：1–2小时学习
- 说人话：窒息、心脏骤停黄金抢救时间极短，身边人施救存活率更高
- 收益：提升窒息、心脏骤停现场生存概率
- 证据等级：A
- 来源：急救医学荟萃分析

12. **更换低钠盐（适合无高钾血症、无严重肾病人群）**
- 成本：食盐小幅涨价
- 说人话：低钠盐替换普通食盐，减少钠摄入、补钾，降低中风风险
- 收益：五年内全因死亡风险下降约12%，中风风险下降14%
- 证据等级：A
- 来源：NEJM随机对照试验

> 本章其余条目：疫苗选择、癌症早期筛查、识别胸痛/卒中预警信号、溺水防护、儿童安全防护等，遵循原书证据体系。

# 2. 不要慢慢死
> 主题：慢性病长期风险，条目按性价比从高到低排序

1. **每周累计150分钟中等强度运动（快走、骑行、慢跑均可，无需健身房）**
- 成本：每周3–5小时，无额外金钱
- 说人话：中等运动降低心血管病、多种癌症、抑郁风险
- 收益：坚持达标，全因死亡风险显著下降
- 证据等级：A
- 来源：荟萃分析

2. **增加蔬菜摄入，减少加工肉类，戒掉含糖饮料**
- 成本：调整饮食采购习惯
- 说人话：加工肉属于一类致癌物；含糖饮料提升肥胖、糖尿病风险
- 收益：降低糖尿病、心脑血管疾病、肠癌风险
- 证据等级：A
- 来源：世界癌症研究基金会报告

3. **年度基础体检，只做高价值筛查项目，拒绝昂贵全套打包体检套餐**
- 成本：几百元，每年半天
- 说人话：绝大多数全套体检套餐包含大量低价值项目，浪费金钱
- 收益：尽早发现高血压、血糖异常、结节等高危问题
- 证据等级：B
- 来源：各国筛查指南

4. **口腔保护：每日刷牙+牙线，定期洗牙**
- 成本：牙线几十元，洗牙每年1–2次
- 说人话：牙周病不仅毁牙，还会加重心血管炎症，后期拔牙、种牙花费极高
- 收益：减少牙周病、掉牙，降低远期全身炎症负担
- 证据等级：B
- 来源：牙周医学队列研究

5. **不要长期久坐，每40–60分钟起身活动几分钟**
- 成本：打断工作的微小毅力
- 说人话：久坐独立提升心血管疾病与血栓风险
- 收益：降低久坐相关慢病风险
- 证据等级：B
- 来源：队列荟萃分析

# 3. 不要浪费精力
> 主题：注意力、情绪、内耗，精力比时间更加稀缺

1. **远离持续消耗你的人际关系，不必强迫讨好所有人**
- 成本：承担短暂的心理不适感
- 说人话：长期消耗型关系持续掏空精力，没有正向回报
- 收益：减少情绪内耗，恢复专注力
- 证据等级：B
- 来源：社会心理学研究

2. **控制无目的刷短视频时长**
- 成本：克制即时快感
- 说人话：算法短视频持续碎片化注意力，降低深度思考能力
- 收益：保护专注力，减少情绪起伏
- 证据等级：B
- 来源：认知心理学实验

3. **拒绝精神内耗：别人的评价很难改变你的现实生活，不要反复回想**
- 成本：练习觉察念头
- 说人话：反复复盘已经发生、无法改变的评价，属于纯粹精力损耗
- 收益：降低焦虑，节省心理资源
- 证据等级：B
- 来源：认知行为疗法研究

4. **学会拒绝，不为面子答应超出能力的请求**
- 成本：短期人情压力
- 说人话：勉强答应，后续你要付出大量时间精力去兑现承诺
- 收益：守住个人精力预算
- 证据等级：C
- 来源：社会行为研究

5. **对抗拖延：大任务拆成5分钟就能启动的小事，降低启动阻力**
- 成本：微小启动成本
- 说人话：拖延不是懒，是任务带来的心理压力过大
- 收益：大幅提升任务完成率，减少拖延带来的焦虑
- 证据等级：B
- 来源：行为心理学

6. **社交原则：少量高质量深度关系 > 大量浅层无效社交**
- 成本：放弃泛人脉圈子
- 说人话：浅层饭局寒暄消耗精力，几乎无法提供实质支持
- 收益：维持稳定社会支持，减少社交疲惫
- 证据等级：B
- 来源：成人发展长期追踪研究

# 4. 不要浪费时间
> 时间不可逆；本节计算时间收益，不折算寿命或金钱

1. **不要长期停留在没有成长、没有回报的工作，评估机会成本**
- 成本：思考、求职、变动带来压力
- 说人话：长期重复无成长岗位，每年消耗大量时间，技能无法积累
- 收益：把时间投入到能积累可迁移能力的事情
- 证据等级：C
- 来源：职业经济学统计

2. **优先学习长期复用技能：阅读、写作、法律常识、沟通、健康知识；避开短期网红技能**
- 成本：持续学习时间
- 说人话：网红短期技巧快速过时，基础能力终身可用
- 收益：长期提升决策质量与收入上限
- 证据等级：B
- 来源：人力资本研究

3. **通勤、排队碎片时间，规划用来听学习内容，不要无意识刷短视频**
- 成本：提前准备音频素材，克制刷手机冲动
- 说人话：每天碎片时间累积起来，一年等于上百小时
- 收益：回收零散时间，持续积累认知
- 证据等级：C

4. **重大决定设置截止时间，不要无限收集信息、无限纠结**
- 成本：接受“信息永远无法完美”
- 说人话：完美主义无限调研，消耗大量时间，错过机会窗口
- 收益：缩短决策周期，避免决策瘫痪
- 证据等级：B
- 来源：决策科学

5. **不要反复回看已经发生、无法改变的事情**
- 成本：觉察反刍思维
- 说人话：沉湎过往，持续占用当下时间与注意力，无法改变事实
- 收益：减少反刍，把注意力放回当下
- 证据等级：B
- 来源：临床心理学

# 5. 不要浪费钱
> 金钱主题；仅做算账参考，**不构成投资建议**

1. **消费底层原则：不需要的东西，再大折扣也是亏损**
- 成本：抵抗促销诱惑
- 说人话：打折只降低单价，不代表你需要这件商品
- 收益：减少冲动消费，省下本金
- 证据等级：C
- 来源：行为经济学

2. **谨慎预付大额储值：健身房、美容店充值，商家跑路维权成本极高**
- 成本：拒绝优惠诱惑
- 说人话：预付卡本质是把钱提前交给对方，存在经营倒闭风险
- 收益：规避大额资金损失
- 证据等级：C
- 来源：市场监管投诉数据

3. **定期检查软件自动续费，关闭不再使用的订阅**
- 成本：10分钟查询核对
- 说人话：很多订阅每月默默扣费，长期累积金额可观
- 收益：每年省下几百至数千元
- 证据等级：C

4. **远离网贷、消费贷；非救命场景绝不使用**
- 成本：克制超前消费欲望
- 说人话：消费贷年化利率普遍很高，很容易陷入债务滚雪球
- 收益：避免高息债务陷阱
- 证据等级：C
- 来源：金融监管警示

5. **普通人理财优先保本，不要幻想低投入暴富；远离高杠杆投机**
- 成本：放弃暴富幻想
- 说人话：高收益承诺基本伴随极高本金亏损风险
- 收益：保住本金，避免一次性大额亏损
- 证据等级：C

6. **区分刚需功能和品牌溢价，不为logo付费**
- 成本：放弃品牌虚荣心
- 说人话：很多高价商品溢价来自营销，产品基础功能并无差别
- 收益：同等使用价值，减少支出
- 证据等级：C

7. **保险购买顺序：医保优先，其次意外险、百万医疗险；最后重疾险，优先保障家庭经济支柱**
- 成本：每年保费预算
- 说人话：很多人顺序颠倒，买一堆理财型保险，基础保障缺失
- 收益：用较低成本对冲大病、意外带来的巨额财务打击
- 证据等级：C

8. **远离刷单、高息理财、荐股导师，绝大多数属于骗局**
- 成本：拒绝高回报诱惑
- 说人话：凡是承诺稳赚不赔、超高利息的项目，大概率是诈骗
- 收益：避免积蓄被骗走
- 证据等级：C
- 来源：反诈中心案例

9. **不要买彩票**
- 成本：放弃中奖幻想
- 说人话：每投入1元，长期平均仅拿回约0.51元
- 收益：长期省下彩票开销
- 证据等级：C
- 来源：财政部彩票统计

# 6. 反面清单：性价比极低的事
> 这些行为收益极小、风险很高，优先停止

- 为面子透支大额消费
- 长期和烂人反复纠缠争吵
- 牺牲长期睡眠换取短视频、游戏短暂娱乐
- 幻想一夜暴富，投入积蓄参与高收益投机
- 掏空家底盲目跟风创业
- 不断牺牲健康、金钱去讨好别人
- 购买昂贵保健品，指望替代正规药物治疗
- 频繁付费算命、情感挽回、玄学咨询

# 7. 没钱的时候怎么活
> 申领补助、低保、失业金、救助，政策各地有差异，以当地当年官方文件为准

1. **失业后及时申领失业保险金**
- 成本：提交材料，办理手续
- 说人话：缴纳失业保险满年限，被辞退后可以按月领取补助
- 收益：获得一段时期稳定现金流
- 证据等级：C
- 来源：《社会保险法》

2. **符合条件可申请低保、临时救助**
- 成本：提交收入、家庭材料
- 说人话：短期陷入绝境时，民政部门有基础救助渠道
- 收益：解决基础生存兜底
- 证据等级：C
- 来源：民政部救助政策

3. **申请医保大病报销，减轻重病负担**
- 成本：保留病历票据
- 说人话：大病医保在基础医保之上，二次报销高额医疗费用
- 收益：降低重病致贫风险
- 证据等级：C

# 8. 别把自己搭进去：法律与财产安全
> 保护人身自由与财产；法条以最新官方版本为准

1. **不要出借身份证、银行卡、电话卡，涉嫌帮信罪**
- 成本：拒绝亲友借卡请求
- 说人话：卡被拿去洗钱、诈骗，卡主需要承担刑事责任
- 收益：避免刑事犯罪记录、罚金
- 证据等级：C
- 来源：刑法帮信罪条款

2. **欠薪、无故被辞退，保留证据，了解劳动仲裁渠道**
- 成本：保存劳动合同、工资流水、聊天记录
- 说人话：劳动仲裁维权成本低，不需要必须请律师
- 收益：拿回拖欠工资、违法辞退补偿金
- 证据等级：C
- 来源：劳动合同法

3. **合同、借条签字前逐行阅读，不要随意担保**
- 成本：花时间阅读文本，拒绝人情担保
- 说人话：一旦担保，对方欠债你需要代为偿还
- 收益：避免莫名背负巨额债务
- 证据等级：C

4. **租房、交易，全程保存聊天记录、转账凭证**
- 成本：归档保存证据
- 说人话：产生纠纷时，聊天、转账记录是核心证据
- 收益：维权时有证据支撑
- 证据等级：C

5. **网络发言守住底线，不造谣、不网暴、不辱骂他人**
- 成本：发言前三思
- 说人话：网络不是法外之地，诽谤、侮辱需要承担民事甚至刑事责任
- 收益：避免被起诉、行政处罚
- 证据等级：C

6. **遭遇电信诈骗，立刻拨打110/96110申请止付**
- 成本：第一时间报警
- 说人话：转账后越快报警，冻结追回资金可能性越高
- 收益：有机会挽回被骗资金
- 证据等级：C
- 来源：反诈中心指引

# 9. 普通人容易踩的法律红线
> 很多行为普通人以为没事，实际面临拘留、罚款、判刑

1. **不要随意转发未经核实的灾难、事故谣言**
2. **高空抛物属于违法，造成损伤要承担刑事责任**
3. **不要非法捕捉、买卖保护野生动物**
4. **网络传播淫秽视频图片，涉嫌传播淫秽物品罪**

# 10. 恋爱和结婚划不划算
> 仅拆解金钱、时间、法律、健康风险；不做道德判断，不强制替你做决定

1. **婚恋优先看人品、责任感、情绪稳定，其次才是浪漫外表**
- 成本：耐心观察，不要快速投入大额金钱
- 说人话：短期浪漫容易伪装，长期相处靠稳定人格
- 收益：降低婚姻内耗、家暴、财务欺骗风险
- 证据等级：B
- 来源：婚姻长期追踪研究

2. **生育是极高成本选择，慎重评估经济、精力、家庭支持，不要随大流**
- 成本：大量金钱、十几年时间精力
- 说人话：生育会永久改变人生现金流、自由时间、身体状态
- 收益：自愿选择，清楚代价之后再决定
- 证据等级：C

3. **婚前理清财产，大额资金往来写清楚凭证**
- 成本：谈钱的尴尬
- 说人话：彩礼、房产出资、债务，提前厘清，减少离婚纠纷
- 收益：规避大额财产纠纷
- 证据等级：C

# 11. 程序员和技术人容易踩的红线
> 代码相关行为的刑事风险

1. **未经授权不要爬取、抓取平台大量用户隐私数据**
2. **不要制作、传播木马、病毒、破解程序**
3. **不要擅自入侵别人服务器，哪怕只是“测试”**

# 12. 创业与做生意：别把家底赔进去
1. **区分个人债务和公司有限责任，不要随便签个人连带担保**
- 成本：仔细阅读合同条款
- 说人话：一旦签连带担保，公司欠债可以直接执行你的个人房产存款
- 收益：隔离个人家庭资产风险
- 证据等级：C

# 13. 紧急情况：先做什么
1. **有人心脏骤停，立刻拨打120，马上心肺复苏，等待AED**
- 成本：提前学习操作
- 说人话：心跳骤停，4分钟内是黄金抢救窗口
- 收益：提升现场生存概率
- 证据等级：A
- 来源：急救医学指南

2. **气道异物窒息，立刻实施海姆立克**
3. **火灾逃生优先撤离，不要贪恋财物；低姿捂口鼻**

# 14. 账号与信息安全
1. **重要账号开启二次验证（2FA）**
- 成本：安装验证App，多一步操作
- 说人话：即使密码泄露，对方也无法登录
- 收益：大幅降低账号被盗风险
- 证据等级：C

# 15. 租房与买房
1. **租房签约前核验房东房产证、身份证，核对是不是本人**
2. **租房押金条款写进合同，退房条件写清楚**
3. **买房重点算总贷款利息，不要只看月供数字**

# 16. 得了慢性病之后怎么活
1. **慢性病药物坚持遵医嘱，不可自行断药、随意减量**
2. **固定复查，记录血压、血糖指标，方便医生判断**

# 17. 家里有老人
1. **提前沟通意定监护、遗嘱安排，趁老人意识清晰办理**
- 成本：公证费用，沟通的心理压力
- 说人话：失能之后再处理，家人容易产生巨大纠纷
- 收益：减少遗产、监护纠纷
- 证据等级：C

# 18. 养孩子划不划算
> 拆解养育金钱、时间成本，不强制建议生或者不生

# 19. 在职、离职和工伤
1. **被公司辞退，分清是协商解除、违法解除，核算补偿金**
2. **保留考勤、加班记录，加班费依法可以主张**
3. **工伤第一时间申报，不要私下签署放弃赔偿协议**

# 20. 刚出生的孩子怎么带
1. **新生儿窒息、呛奶的识别与急救**
2. **按时完成国家一类免费疫苗**

# 21. 出国、旅行与境外安全
1. **出国购买境外旅行保险，牢记12308领事保护热线**
2. **境外遵守当地法律，国内法律在国外不适用**

# 22. 怎么放松：娱乐场所和减压
1. **优先低成本减压：户外光照、快走；不要依靠酗酒解压**
- 成本：外出时间
- 说人话：光照、运动改善情绪，酒精短期麻痹，长期加重抑郁
- 收益：改善情绪，不产生成瘾副作用
- 证据等级：B

# 23. 学什么技能划算
1. **优先选择不容易被AI快速替代、具备人际/实操门槛的技能**
2. **学历提升的回报，结合自身年龄、成本综合计算**

# 24. 看病：怎么少花钱少走弯路
1. **小病优先社区/基层医院；大病再转诊三甲，分级就诊**
2. **看病带齐既往检查报告，避免重复检查花钱**
3. **拒绝医院门口医托**

# 25. 人走了以后要办什么
1. **死亡证明、销户、丧葬补助、抚恤金申领流程**
2. **清理逝者账户、资产、债务**

# 26. 做一个网站或平台：资质、备案和服务器
> 网站备案、ICP、网络内容合规责任

# 27. 怀孕和生产：从发现怀孕到出院办证
1. **按时产检，识别子痫前期、产后大出血高危信号**
2. **了解生育津贴、产假政策**

# 28. 别为了外形把身体搞坏
1. **不要网购来路不明减肥药、美容针；医美选择正规医疗机构执业医师**
- 成本：拒绝低价医美诱惑
- 说人话：非法医美可致失明、感染、休克死亡
- 收益：规避严重致残致死风险
- 证据等级：B

# 29. 遭遇重大打击之后
> 重病、丧亲、离婚、失业
1. **重大变故发生的几周至一年，不要仓促做出买房、大额投资、辞职等不可逆重大决定**
- 成本：推迟重大决策
- 说人话：应激状态下判断力下降，容易做出后悔的选择
- 收益：避免情绪驱动下的重大损失
- 证据等级：B

2. **出现持续自杀念头，拨打心理援助热线，寻求正规精神科门诊**

# 30. 上学以后的孩子
1. **儿童溺水、交通头盔防护；窝沟封闭、散瞳验光**
2. **不要购买号称“治愈近视”的产品**

# 31. 十八岁之后有哪几条路
> 考公、当兵、学历提升、灵活就业社保等法定路径

# 32. 出国留学：身份、打工、保险和回国认证
> 签证、境外打工时限、学历认证，政策变动快，以官网最新为准

# 33. 残疾之后怎么活
> 残疾人证、两项补贴、长期护理保险、劳动能力鉴定

# 34. 家里常备药别吃出事
1. **退烧药、止痛药不要叠加多种复方感冒药，避免肝损伤**
2. **药品保留原包装，看懂禁忌、剂量，不要凭经验加倍服用**

## 后记
本书的核心，**不是苦行，不是抠门，不是要求你全部做到**。
人生有四种不可再生资源：寿命、时间精力、金钱、选择权（自由）。
高性价比的人生，就是把有限资源，持续投入到长期稳定正向回报的事情；
避开那些一次性就可以摧毁多年积累的重大风险。

你不用一次性全部落地。每次挑选1–2条，慢慢执行，长期就能显著改善生活。
